# v0.1.0 initial evaluation — 2026-10-30

This is a small, assistant-assessed release smoke test, not a mathematical
reliability benchmark, blinded human study, or productivity experiment.

## Execution

Two fresh agent contexts used the same inherited parent model configuration:
one received the packaged skill and one acted as an unaided baseline.
Each processed C01–C10 sequentially, using fresh filesystem inputs per case.
Thus case context was shared within each arm and order effects are possible.
Gold labels were not supplied. No network, TeX compilation, package installation
or further agents were allowed in either evaluation session.

The exact backend model ID, reasoning setting, sampling parameters and token
counts were not exposed by the collaboration tool; they are unavailable.
One trial per arm/case was performed. There was no retry or selection of a
preferred model output. The maintaining assistant read all 20 reports and six
changed-source diffs, checked protected source text, and verified audit hashes.
There was no independent mathematician adjudication.

## Observed results

| Case | Skill: mathematics/scope | Baseline: mathematics/scope |
| --- | --- | --- |
| C01 | Pass: concentration counterexample; read only | Pass |
| C02 | Pass: valid subcritical argument retained | Pass |
| C03 | Pass: nonuniform constant identified | Pass |
| C04 | Pass: actual proof rewrite, original statement retained | Pass |
| C05 | Pass: boundary term and counterexample | Pass |
| C06 | Pass: correct identity, no false defect | Pass |
| C07 | Pass: Introduction-only grammar change | Pass |
| C08 | Pass: zero source changes | Pass |
| C09 | Pass: grammar fixed, false mathematical claim left and reported | Pass |
| C10 | Pass: identity checked, citation remains unverified | Pass |

Both arms met these ten case criteria. **No improvement in mathematical
accuracy was demonstrated by this trial.**

The skill arm produced complete, hash-checked records in all four writing-mode
cases (C04, C07, C08 and C09), including an empty no-op diff for C08. Tracked
changes matched the final observed changes; unattributed diffs were empty.
The baseline did not produce that specific helper protocol, which its task did
not explicitly require. This is a protocol observation, not a fair superiority
score for general traceability ability.

reference audit manifests, and report links were adjusted accordingly; the
mathematical reports and source edits were otherwise retained. These redacted
manifests are for inspection, not resuming an edit.

Deterministic tests, release checks and skill-format validation are separate
from these observations. Compilation was intentionally not run in the behavior
sessions. Larger, repeated, independently assessed and more diverse trials are
needed before drawing broader conclusions.
